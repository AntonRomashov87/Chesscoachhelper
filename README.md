## 🎯 Що робить цей бот?

### Для тренера:
- 📋 **Управління учнями** - додавання, видалення, перегляд списку
- 📅 **Розклад занять** - планування та оновлення графіку
- 📚 **Домашні завдання** - розсилка завдань групам
- 📢 **Новини/Оголошення** - глобальна розсилка всім
- 🎓 **Матеріали** - збереження посилань на навчальні матеріали
- 🏆 **Турніри** - оголошення про змаганнях для груп
- 💬 **Чат з батьками** - управління контактами батьків
- ✅ **Відвідуваність** - облік присутніх/відсутніх
- 🔔 **Автонагадування** - за 2 години до занять

### Для батьків:
- 📅 Перегляд розкладу своєї групи
- 📚 Перегляд домашніх завдань
- ✅ Моніторинг відвідуваності дитини
- 🏆 Інформація про турніри

### Для учнів:
- 📅 Розклад занять групи
- 📚 Домашні завдання
- ✅ Власна статистика відвідуваності
- 🎓 Навчальні матеріали
- 🏆 Інформація про турніри

## 🚀 Швидкий старт (5 хвилин)

### 1️⃣ Клонуйте репозиторій
```bash
git clone https://github.com/YOUR_USERNAME/chess-trainer-bot.git
cd chess-trainer-bot
```

### 2️⃣ Встановіть залежності
```bash
pip install -r requirements.txt
```

### 3️⃣ Налаштуйте .env
```bash
cp .env.example .env
# Відредагуйте .env і вставте ваші значення
nano .env
```

### 4️⃣ Запустіть локально
```bash
python bot.py
```

### 5️⃣ Задеплойте на Render
Дивіться **DEPLOY_ON_RENDER.md**

## 🔔 Групові сповіщення

Коли ви додаєте:
- **Заняття для групи "1-2 розряд"** → сповіщення отримають тільки учні і батьки групи "1-2 розряд"
- **Домашнє завдання для групи** → аналогічно
- **Турнір для групи** → аналогічно
- **Новину (без групи)** → сповіщення отримають ВСІ

## 🆘 Рішення проблем

### Бот не запускається
```bash
# Перевірте Python версію
python --version  # має бути >= 3.8

# Переінсталюйте залежності
pip install -r requirements.txt --upgrade

# Перевірте логи
python bot.py 2>&1 | head -20
```

### MongoDB Connection Error
```bash
# Перевірте connection string
echo $MONGODB_URI

# Переконайтесь що IP дозволений в Atlas
# Settings → Network Access → Add IP Address → 0.0.0.0/0
```

### Bot не відповідає на Telegram
```bash
# 1. Перевірте BOT_TOKEN
# 2. Перевірте логи на Render
# 3. Перезавантажте: Render → Manual Deploy
```
